# MarketMate AI - AI Marketing SaaS

**AI-Powered Marketing Content Generation Platform**

MarketMate AI is a web-based SaaS platform that uses generative AI (Google Gemini API) to automate everyday marketing content creation - captions, hashtags, SEO copy, emails, ad copy, slogans, and more - from a single dashboard.

## Problem Statement

Marketers and small businesses need to create social-media and marketing content regularly. Manual brainstorming, writing, and editing take considerable time, and the same idea must often be rewritten in different styles and tones for each platform.

## Features / Modules

- Ad Copy Generator
- Product Description Generator
- Slogan Generator
- AI Caption Generator
- Hashtag Generator
- SEO Writer
- Email Marketing
- Competitor Analysis
- Image Generator
- Landing Page Builder
- Post Scheduler
- Analytics Dashboard
- History

## Tech Stack

**Frontend:** React.js, Vite, JavaScript, HTML and CSS
**Backend:** Python, Flask (REST API), Python virtual environment
**Database:** SQLite
**AI Layer:** Google Gemini API (google-generativeai, LangChain)

## Installation and Setup

### Frontend Setup
cd client
npm install
npm run dev

Frontend runs at http://localhost:5173

### Backend Setup
cd server
python -m venv venv
.\venv\Scripts\activate
pip install -r requirements.txt
python app.py

Backend runs at http://127.0.0.1:5000
